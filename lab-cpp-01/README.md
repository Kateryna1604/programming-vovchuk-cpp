## Хід роботи

**У лабораторній роботі було створено два класи:**

Mail

**Клас призначений для зберігання інформації про повідомлення та містить:**

тему повідомлення;
текст повідомлення;
відправника.

**Для класу були реалізовані:**

конструктор за замовчуванням;
конструктор з параметрами;
конструктор копіювання;
оператор присвоювання;
деструктор;
гетери та сетери;
метод виведення інформації.

MailList

**Клас використовується для зберігання колекції об’єктів Mail.**

**Для нього реалізовано:**

динамічний масив об’єктів;
додавання елементів;
видалення елементів;
пошук повідомлень користувача;
отримання елемента за індексом;
автоматичне збільшення розміру масиву.

Також для перевірки роботи програми були створені модульні тести за допомогою Google Test Framework.
