## Хід роботи

У цій лабораторній роботі було розширено попередній проєкт та додано перевантаження операторів для класів Mail і MailList.

**Для класу Mail було реалізовано:**
оператор присвоювання =;
оператор порівняння ==;
оператор порівняння !=;
оператор виведення <<;
оператор введення >>.
**Для класу MailList було реалізовано:**
оператор індексації [];
оператор виведення <<;
оператор введення >>;
роботу із файлами через потоки ifstream та ofstream.

**Також було збережено функціональність попередньої лабораторної роботи:**

додавання повідомлень;
видалення повідомлень;
пошук повідомлень за відправником;
автоматичне збільшення розміру динамічного масиву;
запис та читання списку повідомлень з файлу.

Для перевірки правильності роботи програми були створені модульні тести за допомогою Google Test Framework.

## Висновок

Під час виконання лабораторної роботи я навчилася перевантажувати оператори для власних класів у C++. За допомогою тестів і Valgrind вдалося переконатися, що програма працює правильно та не має витоків пам’яті.
