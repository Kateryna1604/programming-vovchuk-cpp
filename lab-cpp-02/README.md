## Хід роботи

У цій лабораторній роботі за основу була взята попередня лабораторна з класами Mail та MailList.

Було замінено використання функцій printf та scanf на потоки cout і cin.

Для роботи з рядками використовувався тип std::string, а для формування текстового представлення об’єкта — stringstream.

**У класі Mail були реалізовані методи:**

toString() — для перетворення об’єкта у текстовий рядок;
fromString() — для створення об’єкта з рядка.

**У класі MailList були реалізовані:**

запис списку повідомлень у файл;
зчитування списку повідомлень з файлу;
пошук повідомлень за автором;
додавання та видалення повідомлень;
сортування повідомлень.

Також було створено модульні тести для перевірки роботи основних методів.
