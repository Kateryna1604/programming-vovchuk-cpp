## Хід роботи

У цій лабораторній роботі було створено шаблонний клас List, який реалізує динамічний масив та може працювати з будь-яким типом даних.

**Для класу були реалізовані такі методи:**

виведення елементів масиву на екран;
пошук індексу елемента;
сортування масиву;
пошук мінімального елемента;
додавання нового елемента до кінця масиву;
видалення елемента за індексом.

Клас реалізований за допомогою шаблонів, тому його можна використовувати для різних типів даних без дублювання коду.

**Для демонстрації роботи були використані:**

список цілих чисел (List<int>);
список рядків (List<std::string>).

Також було реалізовано автоматичне збільшення розміру внутрішнього масиву при нестачі пам’яті.

## Результат роботи програми
INT LIST:
10 3 7 1

MIN = 1

INDEX OF 7 = 2

SORTED:
1 3 7 10

AFTER REMOVE:
1 7 10

STRING LIST:
banana apple orange

MIN = apple

SORTED:
apple banana orange
